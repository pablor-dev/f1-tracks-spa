# F1 Tracks

F1 Tracks es una aplicación web de una sola página dedicada a explorar los circuitos de Fórmula 1. El proyecto busca presentar información de cada pista en una experiencia clara, visual y fácil de navegar.

## Objetivo

Construir una base moderna y extensible para consultar circuitos, conocer sus características principales y ampliar progresivamente la experiencia con datos y contenido relevante de la Fórmula 1.

## Estado

Proyecto en etapa inicial.
