# F1 Tracks SPA

An interactive, mobile-first Single Page Application for exploring current Formula 1 circuits.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Vitest and Testing Library
- ESLint
- pnpm

## Requirements

- Node.js 22 or later
- pnpm 11.18.0

## Commands

```bash
pnpm install
pnpm dev
pnpm test
pnpm lint
pnpm build
```

Repository conventions and quality requirements are documented in [`AGENTS.md`](./AGENTS.md).
